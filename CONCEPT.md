# Утверждённая концепция лендинга

Пользователь выбрал **01 «Кинематограф»** из своего архива `russkie_pomestya_concepts.zip` как основное направление для дальнейшей разработки всего лендинга.

## Источник

- Вариант A из исходного архива; в текущем `index.html` это секция `#home`. По прямой просьбе пользователя надзаголовок «Строительная компания „Русские поместья“» удалён. Основной заголовок, описание и кнопка сохранены.
- Контрольный скриншот: `provided/rp_checked_a_1440.png`.
- Исходный HTML в архиве: `russkie_pomestya_three_final_concepts.html`.

Выбран именно вариант из архива пользователя. Более ранние разработки в `variants/` и два других варианта архива не являются основой дальнейшей работы.

## Основа оформления

- Фотография дома на весь первый экран.
- Тёмный фон и затемнение под текстом.
- Тёплый свет на фотографии и золотистый акцент основной кнопки.
- Крупный заголовок без засечек, предложение слева, факты о компании внизу.
- Последующие разделы должны продолжать характер выбранного первого экрана.

## Единая типографика заголовков

По указанию пользователя все восемь заголовков блоков после первого экрана используют общий класс `.section-title` из `assets/cinema.css`. Общие параметры — семейство шрифта, размер, насыщенность 700, обычное начертание, межстрочный и межбуквенный интервалы, цвет и нулевой внешний отступ. Для телефона используется одно общее медиаправило. Индивидуальные настройки типографики у галереи, ипотеки, комплектаций и других разделов удалены; локальные правила задают только ограничения ширины и компоновку.

Первый экран с H1 исключён из этого правила. Текст всех блоков сохранён. Проверка вычисленных браузером стилей на семи ширинах — `research/verification-section-titles.json`.

## Действующие требования к продолжению

- Структуру и тексты брать из файла пользователя «Структура с текстами». Тексты первого экрана самостоятельно не переписывать.
- Для фотографий выполненных работ использовать материалы из папки «Фото».
- Водяные знаки на фотографиях сохранять. Не удалять, не менять и не перерисовывать их без прямого указания пользователя. При обработке окружения защищать область знака.
- Использовать официальный логотип «Русские поместья».
- Видео будут из ВК; конкретные ролики предоставит пользователь.
- Сейчас согласовывается визуал. Рабочие формы и сбор заявок не подключать без дальнейшей задачи.
- Предпросмотр и обновления публиковать через GitHub Pages в `Kastet36/ruspom-preview-2`.

## Текущее состояние

Свёрстан полный лендинг: первый экран, фотогалерея, сценарии проживания, комплектации и материалы, ипотека, порядок строительства, видеоотзывы, каталог и контакты.

Первый экран и все разделы объединены почти чёрным фоном `#0a0c0b`. Внизу главной фотографии — плавное затемнение до этого цвета.

Заголовок фотогалереи по указанию пользователя — «Фото реальных домов, которые мы построили». Фотогалерея и видеоотзывы листаются стрелками, свайпами и перетаскиванием мышью. Счётчики и подсказки «Листайте» в блоках страницы убраны по просьбе пользователя.

Видеоотзывы пока представлены четырьмя явно обозначенными местами «Видео скоро». Пользователь передаст ролики из ВК позднее. Данные роликов находятся в `assets/cinema/videos.json`; плеер создаётся только при открытии карточки с указанным `embedUrl` и удаляется при закрытии.

Контакты свёрстаны без карты. Рабочие формы не подключены. Кнопки первого экрана и выбора проекта ведут к разделу каталога; финальная выдача каталога пока демонстрационная, как на предыдущем этапе согласования визуала.

Основные тексты взяты из файла «Структура с текстами». Формулировки блоков комплектаций и выбора проекта переработаны по согласованным предложениям.

По последующему указанию пользователя восстановлена традиционная визуальная иерархия. Заголовок блока всегда крупнее и насыщеннее внутренних подзаголовков, которые второстепенны. ## Пересмотр блока комплектаций

По предложению пользователя выбран один кадр с подвижной границей между тёплым контуром и готовой отделкой. Два изображения одного интерьера сохраняют общий ракурс, геометрию окон и внешний вид из окна. Меняются внутренние поверхности пола, стен и потолка, встроенная отделка и освещение. Изображения сгенерированы встроенным Imagegen как поясняющие визуализации; это не фотографии выполненных компанией объектов и не спецификация комплектации.

При открытии видны обе половины. Золотистый разделитель перемещается мышью и пальцем; доступно управление клавиатурой. Изображения остаются неподвижными, меняется только область раскрытия. Вертикальный жест на телефоне продолжает прокручивать страницу. Подсказок по управлению и счётчиков нет.

На широком экране слева от кадра находится описание тёплого контура, справа — комплектации с отделкой. На ширине до 1000 px оба описания переходят под изображение, сохраняя соответствие его сторонам. Отдельная строка общей основы убрана, чтобы не повторять содержание подписи. Исходные подробности раскрываются через «Подробнее о материалах». Первый экран и остальные восемь разделов не менялись. Проверки: `research/verification-comparison.json`.

Раздел использует общую сетку лендинга: контейнер 1740 px, одинаковые с соседними разделами внешние поля и размер заголовка. Изображение занимает центральную колонку; боковые описания открытые, без карточек и рамок. Ширина всего раздела больше не зависит от высоты окна. На телефоне используется кадр 16:10. Проверки сетки, адаптивности и ползунка: `research/verification-comparison-layout.json`.
